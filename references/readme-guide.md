# README 优化与竞品研究方法

## 一、竞品研究（阶段 1）

### 检索策略
- 用 `WebSearch` 找品类 Top 3 标杆，关键词组合：
  `<品类> best open source / top app / features / UI design / reddit review`。
- 音频转写/字幕类常青标杆：MacWhisper、WhisperX、realtime-captions、
  desktop-audio-to-text（Windows WASAPI 同类）、TMSpeech（国产）、Buzz、OBS 字幕插件。
- 每个案例用三栏归纳：

| 维度 | 要记录的要点 |
|------|------|
| 核心优势 | 解决什么痛点、为何好用（隐私本地/实时性/准确率/多语言） |
| 特色亮点 | 差异化功能（双引擎、悬浮字幕、唱词、多格式导出、离线） |
| UI 审美 | 风格（极简/毛玻璃/iOS/终端/悬浮）、配色、版式、动效取向 |

### 归纳差异化
- 我们 vs 标杆的独特卖点，落到一句话定位（中英双语）。
- 例：双引擎兜底（云快+本地稳）× iOS 毛玻璃 UI × 自动断句时间戳 × 历史卡片。

### 研究产出要落到 README 的哪里
- 「核心优势」表：把 3–6 条借鉴来的设计写成「痛点 → 我们的方案」两列。
- 「同类差异对比」表：横向列出 3–5 个标杆的定位，点明**我们不做全家桶**的那一件事。
- 「设计理念」段落：把标杆的 UI 取向（Fluent / 毛玻璃 / 极简）转成本项目的配色与版式决定。

## 二、README 最佳结构（阶段 2）

按顺序组织，层次清晰、可扫读：

1. **标题 + 一句话定位**（中英双语）
2. **Shields 徽章**：平台、引擎、UI 风格、语言、离线能力、许可证
3. **导航目录**（锚点链接，长文档必备）
4. **项目简介**：3–5 句讲清它是什么、给谁用
5. **核心优势**（表格）：对比痛点 → 我们的方案
6. **功能特性**（清单/表格）：逐项能力 + 参数表
7. **UI 设计理念**：配色、圆角、毛玻璃、字体、交互；可贴设计原则
8. **截图演示**：说明页长图 + 图标尺寸对照（用真实截图，不要占位图）
9. **快速开始**：安装 → 运行的最短路径（3 步内）
10. **配置**：如云引擎密钥如何填（用 `config.json.example`，不写真实密钥）
11. **构建**：打包 exe / venv 等
12. **工作原理**：mermaid 架构图（捕获 → 引擎 → 转写 → UI）
13. **目录结构**：树状列出关键文件与作用
14. **使用场景**：举例（会议字幕、网课笔记、视频转写）
15. **常见问题 FAQ**：高频报错与对策，用 `<details>` 折叠（含本项目踩过的坑）
16. **路线图 Roadmap**：近期/远期计划
17. **贡献指南 + 许可证**

### 写作要点
- 多用**表格**与**清单**，少用大段文字。
- 技术术语中英并列（如「回环捕获 / loopback capture」）。
- 代码示例用围栏块，命令加中文注释。
- 保持专业、克制，不堆砌形容词。
- 徽章数量控制在 6–8 枚；`shields.io` 的静态徽章最稳，动态徽章（stars/downloads）可能因网络不可达而破图。

## 三、UI 审美落地方向（供「UI 设计理念」章节参考）
- **毛玻璃 / 半透明**：`SetWindowCompositionAttribute` + 模糊，背景虚化。
- **全圆角 + 简洁配色**：低饱和主色 + 中性灰，按钮大圆角。
- **层次清晰**：标题/正文/次要信息三级字号；状态用 subtle 色差。
- **深浅双主题**：跟随系统深浅色（或用 `localStorage` 记忆选择），
  深色配色基准 bg `#0B1220` / surface `#0F172A` / text `#E2E8F0` /
  accent `#38BDF8` / border `#1E293B`。
- **交互反馈**：悬停态、点击态、加载态明确；操作有即时状态提示。
- **可访问**：对比度达标，不依赖纯颜色传达信息。

## 四、README 本地配图（截图）做法

README 里的截图不要依赖外链，**放到仓库的 `docs/` 目录**并相对引用：

```markdown
<p align="center">
  <img src="docs/preview.png" width="820" alt="界面预览">
</p>
```

生成方法（沙箱内无 GUI 时）：用 Edge/Chrome 无头模式截本地 HTML：

```bash
msedge --headless --disable-gpu --hide-scrollbars \
       --window-size=1100,1600 \
       --screenshot="docs/preview.png" "file:///D:/项目/使用说明.html"
```

- 截完检查底部多余留白，用 Pillow 按内容裁掉 (`getbbox()` 定位非背景行)。
- 截图体积控制：PNG 超过 ~800KB 时考虑转 JPEG 或降采样，避免仓库膨胀。
